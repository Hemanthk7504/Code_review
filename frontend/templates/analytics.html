Framework Scientific Evaluation Reference

Evaluation Methodology

Every finding carries verification, risk_score, and sources; every revision carries risk_before, risk_after, resolved/targeted, and new_findings. Run the /review and /revise endpoints on labelled benchmark repositories to verify precision, recall, and false-positive resilience.

Zero-Regression Acceptance Gate

Autonomous revisions are accepted if and only if: the revised code compiles with a valid Python AST, 100% of targeted issues are eliminated without regressions, zero new security vulnerabilities appear, and overall risk score decreases.
